## Typography

All roles use the established project scale. No new sizes introduced.

| Role | Size | Weight | Line Height | Tailwind | Font | Usage |
|------|------|--------|-------------|----------|------|-------|
| Body | 16px | 400 (regular) | 1.5 | `text-base leading-relaxed` | Inter Tight | InsightsBlock body copy, healing direction text |
| Small / label | 12px | 400 (regular) | 1.5 | `text-xs tracking-[0.15em] uppercase text-ink-faint` | Inter Tight | Section labels ("Zielvorschläge", "Mögliche Hindernisse", "Unterversorgte Wertebereiche") |
| UI small | 14px | 400 (regular) | 1.4 | `text-sm` | Inter Tight | Score string, suggestion bullet text, gap hint text, button label |
| Heading (card) | 24px | 500 (medium) | 1.2 | `display text-2xl text-ink` | Fraunces | Schema name as card heading — matches existing module summary heading pattern |

Rules:
- Schema name heading: `display text-2xl text-ink` — same pattern as `SyntheseModule.tsx` line 348.
- Section labels (Zielvorschläge, Mögliche Hindernisse, Unterversorgte Wertebereiche):
  `text-xs tracking-[0.15em] uppercase text-ink-faint` — exact established small-caps label pattern.
- Healing direction paragraph: `text-sm text-ink-soft leading-relaxed` — secondary body copy.
- Score string: `text-sm text-ink-faint` — shown inline with schema name heading.
- Suggestion bullet items: `text-sm text-ink` — primary readable text.
- Obstacle hint items: `text-sm text-ink-soft` — lower visual weight than suggestions.
- Values gap value label: `text-sm text-ink` with gap badge `text-xs text-ink-faint`.
- Values gap hint text: `text-xs text-ink-soft italic` — de-emphasised contextual note.

## Component Specifications

### InsightsBlock — outer container

**File:** `frontend/src/modules/synthese/InsightsBlock.tsx`

**Placement in SyntheseModule:** Immediately after the `dataModules.map(...)` loop (line 339–353 in current SyntheseModule.tsx), before the `<section className="mt-8 print:hidden">` Snapshots section. Rationale from RESEARCH.md: summaries first (what you have), then insights (what it means), then snapshots (how to track change).

**Print behavior:** InsightsBlock does NOT have `print:hidden`. Insights are valuable in a printed therapeutic report.

**Guard condition:** If `allData?.ysq?.answers` is null or undefined, return null. No empty state card, no placeholder — complete absence (per HINT-02 and success criterion 5).

**Outer DOM structure:**

```
<div className="mb-6 space-y-4">
  <h2 className="display text-2xl text-ink mb-4">Hinweise</h2>
  {/* Top-3 YSQ schema Cards */}
  {/* Values gap section — conditional, only if gaps exist */}
</div>
```

Heading "Hinweise" uses `display text-2xl text-ink` — matches existing section headings on Synthese page ("Snapshots" at line 356).

### SchemaInsightCard — one card per top-3 schema

**Container:** `Card` component (renders as `<section>` with `bg-paper-2 border border-line-soft rounded-sm p-6`), with `mb-0` (spacing handled by parent `space-y-4`).

**Internal layout:**

```
Card
  ├── Header row (flex items-baseline justify-between gap-3)
  │     ├── h2: schema name  [display text-2xl text-accent]
  │     └── score badge      [text-sm text-ink-faint]  e.g. "18 / 30"
  │
  ├── Healing direction      [text-sm text-ink-soft leading-relaxed mt-2 mb-4]
  │     (1–2 sentences from SchemaHint.healingDirection)
  │
  ├── Section label          [text-xs tracking-[0.15em] uppercase text-ink-faint mb-2]
  │     "Zielvorschläge"
  │
  ├── Suggestion list        [space-y-1 border-l-2 border-line-soft pl-4 mb-4]
  │     ├── item 1           [text-sm text-ink]
  │     ├── item 2           [text-sm text-ink]
  │     └── item 3           [text-sm text-ink]
  │
  ├── "Als Ziel erkunden"    [type="button" text-sm text-ocean hover:text-ink
  │   button                  transition-colors text-left mb-4]
  │
  ├── Section label          [text-xs tracking-[0.15em] uppercase text-ink-faint mb-2]
  │     "Mögliche Hindernisse"
  │
  └── Obstacle list          [space-y-1 border-l-2 border-line-soft pl-4]
        └── item(s)          [text-sm text-ink-soft]
```

**Score badge format:** `{score} / 30` — space around slash matches German typography convention. Score from `computeSchemaScore()`.

**Schema name:** `display text-2xl text-accent` — Fraunces, 24px, terracotta. Accent color reserved exclusively for schema names in insight cards. No other element in this block uses `text-accent`.

**"Als Ziel erkunden" button:** Inline text button, no background, no border. `type="button"` mandatory. Calls `onNavigateToGoals({ title: schema.label, description: hint.goalSuggestions[0] })`. Ocean tone marks it as distinctly navigational/forward-looking.

**Missing hint guard:** If `YSQ_HINTS_MAP.get(schema.id)` returns undefined, the card for that schema is skipped silently (return null for that item). This prevents crashes when schema IDs drift.

### Values Gap Section — inside InsightsBlock

**Condition:** Rendered only when `getValueGaps(selected).length > 0`. If no gaps exist, the section is fully absent — no empty state.

**Container:** `Card` component with `as="section"`, no extra className.

**Internal layout:**

```
Card
  ├── Section label          [text-xs tracking-[0.15em] uppercase text-ink-faint mb-4]
  │     "Unterversorgte Wertebereiche"
  │
  └── Gap list               [space-y-3]
        └── per-value row    [flex items-start justify-between gap-4]
              ├── value label [text-sm text-ink flex-1]
              ├── gap badge  [text-xs text-ink-faint whitespace-nowrap]
                             e.g. "Lücke 3"
              └── hint text  [text-xs text-ink-soft italic mt-1]
                             (full width, below label + badge row)
```

Revised layout (hint text below the label row, not inline):

```
Card
  ├── heading label (text-xs uppercase)
  └── ul.space-y-3
        └── li per gap value
              ├── div.flex.items-baseline.justify-between.gap-4
              │     ├── span: value label  [text-sm text-ink]
              │     └── span: gap badge    [text-xs text-ink-faint]  "Lücke 3"
              └── p: hint text             [text-xs text-ink-soft italic mt-1]
                    "Dieser Wert wird wenig gelebt — ein möglicher Bereich für ein Ziel."
```

**Gap badge:** `"Lücke {n}"` where n = `item.weight - item.living`. Formatted without units — consistent with existing numeric displays in the codebase.

**Sort order:** Descending by gap size (largest gap first) — consistent with `buildTextReport` and `ValuesSummary`.

**Hint text:** Constant `VALUES_GAP_HINT_TEXT` from `synthese/constants.ts`. Same text for every gap value. Exact copy: `"Dieser Wert wird wenig gelebt — ein möglicher Bereich für ein Ziel."` (from RESEARCH.md A2 — user may revise wording in constants.ts without touching the component).

## Interaction Contract

### "Als Ziel erkunden" button

| Property | Specification |
|----------|--------------|
| Element | `<button type="button">` |
| Visual style | `text-sm text-ocean hover:text-ink transition-colors` — no background, no border, no padding |
| Position | Below the suggestion list, above the obstacle hints section label |
| On click | Calls `onNavigateToGoals({ title: schema.label, description: hint.goalSuggestions[0] })` |
| Callback direction | Prop on `ModuleProps`: `onNavigateToGoals?: (prefill: { title: string; description: string }) => void` |
| App.tsx effect | Sets `goalPrefill` state, calls `setActiveId("goals")` |
| GoalsModule effect | Reads `allData.__goalPrefill` on mount; creates new Goal with prefill; opens it in edit mode (`setOpenId`) |
| Clearing prefill | App.tsx clears `goalPrefill` after single render cycle via `setTimeout(() => setGoalPrefill(null), 0)` in `handleNavigateToGoals` |
| Guard | If `onNavigateToGoals` prop is absent (e.g. in test renders), button is still rendered but onClick does nothing (optional prop) |
| Print behavior | Button is hidden in print via existing global `button { display: none !important }` in print media query (index.css line 64) — correct, no additional class needed |

### Navigation state model

The `onNavigateToGoals` callback is threaded as an optional prop on `ModuleProps<T>` in `registry.ts`. Only `SyntheseModule` calls it. `App.tsx` provides the implementation. This is a props-down / callbacks-up pattern consistent with the existing architecture (no new state library, no context). See RESEARCH.md HINT-04 for full implementation detail.

### No other new interactions

- InsightsBlock is read-only display except for the "Als Ziel erkunden" button.
- Values gap section is purely informational — no interactions.
- No modals, no tooltips, no expand/collapse.
