    3. Add a private helper function `loadSnaps` before the localApi export:

       ```typescript
         const raw = localStorage.getItem(SNAPS_KEY);
         return raw ? (JSON.parse(raw) as SnapshotMeta[]) : [];

       ```

    4. Add three methods inside the `localApi` object, after `importAll`, using named method
       syntax (not arrow functions — consistent with rest of localApi):

       ```typescript
       createSnapshot(label?: string): Promise<SnapshotMeta> {
         const id = crypto.randomUUID();
         const created_at = now();
         const modulesBlob: Record<string, unknown> = {};
         for (const mod of modules) {
           const raw = localStorage.getItem(KEY(mod.id));
           if (raw) modulesBlob[mod.id] = JSON.parse(raw) as unknown;
         }
         const meta: SnapshotMeta = { id, label: label ?? null, created_at };
         const full: SnapshotFull = { ...meta, modules: modulesBlob as Record<string, import("./types").SnapshotModuleEntry> };
         localStorage.setItem(SNAP_KEY(id), JSON.stringify(full));
         const metas = loadSnaps();
         metas.unshift(meta);
         localStorage.setItem(SNAPS_KEY, JSON.stringify(metas));
         return Promise.resolve(meta);
       },

       listSnapshots(): Promise<SnapshotMeta[]> {
         return Promise.resolve(loadSnaps());
       },

       getSnapshot(id: string): Promise<SnapshotFull> {
         const raw = localStorage.getItem(SNAP_KEY(id));
         if (!raw) return Promise.reject(new Error(`Snapshot not found: ${id}`));
         return Promise.resolve(JSON.parse(raw) as SnapshotFull);
       },
       ```

    Note on crypto.randomUUID(): Already used in the codebase (QUAL-03 from Phase 1).
    The uid() utility in lib/uid.ts handles the file:// fallback. However, localApi is only
    used in browser contexts where crypto.randomUUID() is available. Use crypto.randomUUID()
    directly (consistent with existing localApi.putModule pattern if it exists, or use directly).

    If the import of SnapshotModuleEntry causes an inline import in the method body to be
    ugly, add it to the top-level import instead:
    ```typescript
    import type { ModuleRecord, ModuleSpecWire, SnapshotMeta, SnapshotFull, SnapshotModuleEntry } from "./types";
    ```
    Then the full type annotation becomes `modules: Record<string, SnapshotModuleEntry>`.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-08 | Information Disclosure | localApi getSnapshot — localStorage reads | accept | localStorage is same-origin only; single-user tool; no multi-user data isolation needed in local mode |
| T-4-09 | Tampering | serverApi snapshot methods — label field | accept | label is a plain string passed to JSON body; request() wrapper sends auth header; server-side owns validation and parameterization |
