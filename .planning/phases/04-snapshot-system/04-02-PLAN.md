  <behavior>
    SnapshotFullResponse (api.py):
      - id: UUID
      - label: str | None
      - created_at: datetime
      - modules: dict[str, dict[str, Any]]

    POST /api/snapshots:
      - status_code=201
      - counts snapshots for user_id; if >= 200 raises HTTPException(422)
      - reads all ModuleRecords for user_id
      - builds modules_blob = {r.module_id: {"schema_version": r.schema_version, "data": r.data} for r in records}
      - label = payload.get("label") or None
      - snap = Snapshot(user_id=user_id, label=label, data={"modules": modules_blob})
      - returns {id, label, created_at} — NO modules in response

    GET /api/snapshots:
      - selects Snapshot rows WHERE user_id == user_id
      - orders by created_at DESC
      - returns list of {id, label, created_at} — NO data blob per item

    GET /api/snapshots/{snapshot_id}:
      - fetches Snapshot by id + user_id (raises 404 if not found)
      - extracts modules_blob = snap.data["modules"]
      - calls _migrate_snapshot_modules(modules_blob) → returns migrated dict
      - returns SnapshotFullResponse(id, label, created_at, modules=migrated)

    Helper _migrate_snapshot_modules(modules_blob: dict) -> dict:
      - for each module_id, entry in modules_blob.items():
          spec = get_module(module_id)
          if spec is None: pass through unchanged (unknown module)
          stored_version = entry.get("schema_version", 1)
          data = entry.get("data", {})
          if stored_version < spec.schema_version:
              try:
                  data = spec.migrate(data, stored_version)
                  stored_version = spec.schema_version
              except Exception as exc:
                  logger.error("Snapshot migration failed for %r: %s", module_id, exc, exc_info=True)
                  # Return ORIGINAL data — no 500 (QUAL-04 principle)
          result[module_id] = {"schema_version": stored_version, "data": data}
      - snapshots are IMMUTABLE — NEVER write migrated data back to snap.data

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP client → snapshots router | User-supplied label field and snapshot_id path parameter cross here |
| snapshot router → DB | SELECT and INSERT filtered by user_id from Depends(current_user_id) |
| snapshot GET migration → ModuleSpec | spec.migrate() is trusted backend code; exceptions are caught |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-03 | Elevation of Privilege | POST /api/snapshots — user_id | mitigate | user_id always from `Depends(current_user_id)`, never from request payload; mirrors portability.py pattern |
| T-4-04 | Elevation of Privilege | GET /api/snapshots/{id} — ownership | mitigate | SELECT WHERE Snapshot.id == snapshot_id AND Snapshot.user_id == user_id; 404 if not found (prevents cross-user reads) |
| T-4-05 | Denial of Service | POST /api/snapshots — unbounded writes | mitigate | `MAX_SNAPSHOTS = 200` guard: count existing snapshots for user_id; HTTP 422 if >= 200 |
| T-4-06 | Tampering | label field injection | accept | label stored as raw string in JSON column; SQLModel parameterizes queries; label is never executed as code; no XSS risk (React escapes by default) |
| T-4-07 | Denial of Service | GET /api/snapshots/{id} migration loop | mitigate | `_migrate_snapshot_modules` wraps each spec.migrate() in try/except; exception → log + return original, never raise 500 (QUAL-04) |
</threat_model>
