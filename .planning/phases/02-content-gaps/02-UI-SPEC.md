## Component Contracts

### 1. YSQ Module — Mode State

The YSQ module uses the same `mode` pattern as CheckinModule:

```
mode: "overview" | "questionnaire"
```

- Initial mode: `"overview"` if `data.answers` is non-null (results exist), otherwise
  `"questionnaire"`.
- Mode switch: A button on the overview triggers `setMode("questionnaire")` to re-take
  the questionnaire. A button on the questionnaire can return to `"overview"` if results
  already exist.

---

### 2. YSQ Questionnaire — Schema Page Layout

Each of the 18 schema pages renders as a single Card (`bg-paper-2 border border-line-soft
rounded-sm p-6`) containing:

**Header row** (flex, space-between):
- Left: Schema name as `<h2 className="display text-xl">` in `text-ink`
- Right: Progress counter `"Schema X von 18"` in `text-xs tracking-[0.15em] uppercase text-ink-faint`

**Progress bar** (below header):
- A thin horizontal track (`h-0.5 bg-line-soft rounded-full`) with a filled segment
  (`bg-ink-soft rounded-full`) proportional to `(currentSchemaIndex / 18) * 100%`.
- No numeric label on the bar itself (the counter above serves that role).
- Margin: `mt-2 mb-6`

**Question list** (5 items):
Each question follows the ScaleRow pattern from CheckinModule:
- Question text: `text-sm leading-relaxed text-ink mb-3`
- Answer buttons: horizontal `flex flex-wrap gap-2`
- Each button: `px-3 py-1.5 text-sm rounded-sm border transition-colors`
  - Unselected: `border-line-soft text-ink-soft hover:border-ink-soft`
  - Selected: `bg-ink text-paper border-ink`
- Answer scale for YSQ: 4-point Likert — `1 Trifft gar nicht zu`, `2 Trifft kaum zu`,
  `3 Trifft eher zu`, `4 Trifft völlig zu` (exact labels from `reference/kompass.html`)
- Separator: `border-b border-line-soft` between items, `last:border-b-0`

**Navigation row** (`flex gap-3 mt-6`):
- `Zurück` button: `px-4 py-2 text-ink-soft hover:text-ink transition-colors`
  (hidden on schema page 1)
- `Weiter` button (primary when items answered, secondary when schema will be skipped):
  - Items answered: `px-4 py-2 bg-ink text-paper rounded-sm hover:bg-accent transition-colors`
  - Schema not touched: same style but labelled `Überspringen` in `text-ink-soft` variant:
    `px-4 py-2 border border-line text-ink-soft rounded-sm hover:border-ink-soft transition-colors`
- On the last schema (page 18): replace `Weiter` with `Abschließen` (primary filled style,
  always enabled after at least partial answers or skips across all schemas).

---

### 3. YSQ Results — Bar Chart

Rendered in "overview" mode. Full implementation via CSS/Flexbox (no chart package, D-08).

**Container:** `Card` with heading `<h2 className="display text-xl mb-6">Ergebnisse</h2>`

**Bar chart list:** `<ul>` with no bullet, each row is `<li>` separated by
`border-b border-line-soft last:border-b-0 py-3`.

**Each bar row layout:**

```
[Schema name — left, 140px min-width, text-sm text-ink]     [bar track — flex-1]   [score — right]
```

Row is `flex items-center gap-4`.

Schema name column: `text-sm text-ink` in a `<span>` with `min-w-[140px] shrink-0`.

Bar track: `flex-1 bg-paper-3 rounded-sm h-3 overflow-hidden` (the grey rail).
Bar fill inside: `h-full rounded-sm transition-all` with background color per severity
mapping table above, width as `style={{ width: \`${(score / 25) * 100}%\` }}`.
Max score per schema = 25 (5 items × 5 points max — note: YSQ-S3 uses 1–6 scale;
verify against `reference/kompass.html` and adjust max accordingly; use relative
percentage regardless of absolute max).

Score annotation: `text-xs font-mono text-ink-faint ml-2 w-8 text-right shrink-0`.

**Skipped schema row:** Bar fill absent (width 0 or bar track replaced by nothing);
instead of score number show label `"–"` in `text-ink-faint`. Optionally append
`text-xs text-ink-faint italic` label `"nicht ausgefüllt"` after the dash (D-05).

**Ordering:** Schemas sorted descending by score. Skipped schemas sorted to the bottom
of the list (after all scored schemas). No click interaction on rows (D-09).

---

### 4. YSQ Results — Note Fields

Below each bar row: an inline `<input>` field (always visible, D-10).

```
<input
  type="text"
  placeholder="Notiz zu diesem Schema …"
  className="w-full bg-paper border border-line px-3 py-1.5 text-sm rounded-sm
             text-ink placeholder:text-ink-faint focus:outline-none focus:border-ink-soft mt-1"
/>
```

Placed as a second row inside the `<li>`, below the bar row, with `mt-1` gap.
Single-line only (`type="text"`, no `<textarea>`). `maxLength={200}`.

---

### 5. YSQ Questionnaire Restart

In overview mode (results exist), show a secondary action:

```
<button type="button" onClick={() => setMode("questionnaire")}
  className="px-4 py-2 border border-line text-ink-soft rounded-sm
             hover:border-ink-soft transition-colors">
  Fragebogen neu ausfüllen
</button>
```

Placed below the results card, before the disclaimer text.

---

### 6. YSQ Summary Block (Synthese page, CONT-05)

The `YsqSummary` component receives `data: YsqData` and renders:

**If no results yet:**
- `<p className="text-sm text-ink-faint italic">Noch kein YSQ ausgefüllt.</p>`

**If results exist:**
- Heading: `<h3 className="display text-xl mb-3">Auffälligste Schemata</h3>`
  (`text-xl` = 20px, Fraunces — consolidates into existing "subheading" role)
- A list of the top 3 schemas by score (skipped schemas excluded), each as:
  ```
  <div className="flex items-center justify-between py-2 border-b border-line-soft last:border-b-0">
    <span className="text-sm text-ink">{schemaName}</span>
    <span className="text-xs font-mono text-ink-faint">{score}</span>
  </div>
  ```
- No bar chart in summary — text list only, consistent with how ValuesSummary renders
  compact data.

## Interaction States

| State | Trigger | Visual Treatment |
|-------|---------|-----------------|
| Answer button — unselected | Default | `border-line-soft text-ink-soft` |
| Answer button — selected | onClick | `bg-ink text-paper border-ink` |
| `Weiter` — enabled | All 5 items answered | `bg-ink text-paper hover:bg-accent` |
| `Überspringen` — available | 0 items answered on current schema | `border border-line text-ink-soft hover:border-ink-soft` |
| `Abschließen` — enabled | On page 18, always enabled | `bg-ink text-paper hover:bg-accent` |
| Note input — focused | onClick | `focus:border-ink-soft` outline removed |
| Results bar — skipped | Schema has null score | Bar track empty, score shows `"–"` |
| In-progress resume | `data.draft` non-null on mount | Mode starts at `"questionnaire"` at last-answered schema index |
