# Milestone v1.0: Kompass MVP

**Status:** SHIPPED 2026-04-22
**Phases:** 1–4
**Total Plans:** 20
**Total Tasks:** ~40

## Overview

Kompass v1.0 vollständig portiert von der Single-File-HTML-Referenz zu einer modularen FastAPI + React-Webapp. Alle 24 v1-Anforderungen erfüllt: Korrektheit & Stabilität, Abhängigkeits-Upgrades, Content-Module (Checkin, YSQ), Daten-Portabilität (Export/Import), und das Snapshot-System.

## Milestone Summary

**Key Decisions:**

- Generisches Modul-Schema (JSON blob, eine Tabelle) — schnelle Modul-Iterationen ohne Alembic-Rev pro Feld
- Dual-Mode (local + server) via Build-Flag — VITE_STORAGE=local baut Offline-HTML; identische API-Signatur
- Cross-Modul-Refs als {moduleId, id} — Entkopplung für zukünftige Modul-Varianten
- Snapshot-Envelope {modules: {id: {schema_version, data}}} — getrennt vom Export-Format (HTML-v1 flat)
- GET /api/snapshots/{id} ohne user_id-Filter in v1 — Auth nur auf Token-Ebene (fixed nach Code Review)
- Values-Vergleich per label.toLowerCase() — IDs ändern sich über Schema-Versionen, Label ist stabil

**Deferred Items:**

- Phase 2 VERIFICATION.md: 3 YSQ-Browser-Rendering-Tests (human_needed, visuell verifiziert in UAT-Session)
- WR-01 bis WR-04 aus Code Review Phase 4: alle behoben vor Milestone-Close

**Technical Debt:**

- localApi MAX_SNAPSHOTS-Limit nachgezogen (WR-01)
- v2 Requirements (TEST-01..03, UX-01..03, INFRA-01..02) für nächste Milestone
